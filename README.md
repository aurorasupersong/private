# F.AGENT 趋势企划原型

这是一个静态交互原型，演示“趋势洞察 → 企划报告 → Design Brief → 智能设计 → 结果回流”的流程。

## 项目文件

- `temu-trend-prototype.html`：原型源码
- `assets/`：源码页面引用的示例商品图片
- `dist/index.html`：可直接部署的静态页面
- `dist/assets/`：部署页面引用的示例商品图片

## 预览

直接打开 `dist/index.html`，或将 `dist/` 目录作为静态站点根目录部署。项目不需要构建依赖。

## 演示说明

商品、趋势和经营指标为演示数据；“智能设计”交互用于展示流程，不会调用真实图像生成模型。
